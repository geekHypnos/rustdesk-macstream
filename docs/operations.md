# 双 Mac 使用与排障指南

状态：P1 草案。已验证 Tailscale Direct IP 可建立连接；仍需完成键鼠、剪贴板、重连和稳定性验收。

本文使用“设备 A（控制端）”和“设备 B（被控端）”，不记录真实设备名、地址、账号或密码。

## 1. 前提

- 两台 Mac 安装官方 Tailscale，并由用户在官方客户端自行登录同一可互访网络。
- 两台 Mac 安装相同基线版本的 RustDesk；按 Apple Silicon 或 Intel 选择对应安装包。
- 不向项目提供 Tailscale 登录信息、认证密钥、完整设备列表或 RustDesk 密码。

Tailscale 显示设备在线只代表网络状态，不保证 RustDesk 正在运行、Direct IP 已开启或认证能够通过。

## 2. 配置被控端

在设备 B 打开 RustDesk：

1. 进入“设置 → 安全”，解锁安全设置。
2. 开启 Direct IP access；默认端口为 `21118`，除非明确改变过，否则保持默认。
3. 无人值守使用时，选择通过密码接受会话，并设置固定强密码。
4. 若存在“仅当 RustDesk 窗口打开时允许连接”，无人值守场景应关闭它。
5. 在 macOS“系统设置 → 隐私与安全性”中授予 RustDesk 屏幕录制和辅助功能权限；键盘异常时同时核查输入监控。
6. 完全退出并重新打开 RustDesk，使权限及监听设置生效。

固定密码只能由用户在 RustDesk 界面设置。项目文档、日志、命令、测试夹具和 GitHub 均不得保存真实密码。

## 3. 发起连接

1. 在设备 A 的 Tailscale 官方客户端或管理页面找到设备 B 的地址。
2. 在 RustDesk“控制远程桌面”输入框填入该地址，而不是 RustDesk 数字 ID。
3. 首次连接时输入固定密码并选择记住密码；以后可从历史连接直接进入。
4. 保存密码属于 RustDesk 本机功能；本项目不读取、同步或代管它。

## 4. 显示和输入

远端分辨率大于本机时，在会话工具栏的显示菜单选择“自适应/适应窗口”，不要使用“原始”显示。需要长期生效时，在设备 A 的“设置 → 显示 → 默认显示样式”选择“自适应”。

若字母键被解释为方向或快捷键：

1. 确认光标位于文本输入框。
2. 在会话工具栏的键盘菜单切换输入源；macOS 可尝试 Input source 2。
3. 核查控制端的输入监控权限和被控端的辅助功能权限。
4. 退出会话并重新打开 RustDesk，再测试普通英文及中文输入。

## 5. 状态与故障处理

| 表现 | 处理 |
| --- | --- |
| Tailscale 未安装 | 打开官方下载安装页面，或跳过并使用 RustDesk 原有方式；不自动安装 |
| 需要登录 | 打开官方客户端，由用户自行登录；不收集凭据 |
| 已登录但暂停或断开 | 打开官方客户端，由用户手动恢复；不自动重连 |
| 状态无法解析 | 显示“未知”，允许重试或手填地址，不猜测在线 |
| 连接被拒绝 | 检查 RustDesk 是否运行、Direct IP 是否开启、端口是否一致，并重启 RustDesk |
| 连接超时 | 检查两端 Tailscale 在线状态、访问策略和网络，不直接归因于 RustDesk |
| 密码失败 | 由用户在被控端重新设置或确认密码；不得将密码发到日志或 issue |
| 能看不能控制 | 检查被控端辅助功能和控制权限 |
| 黑屏或画面缺失 | 检查被控端屏幕录制权限，重新打开 RustDesk |
| 键盘映射异常 | 切换会话键盘输入源，并核查输入监控权限 |
| 画面过大 | 选择自适应显示；必要时再降低被控端系统分辨率 |

## 6. 基线验收

- [x] 通过 Tailscale 地址建立 Direct IP 连接。
- [ ] 鼠标点击和窗口拖动正常。
- [ ] 英文、中文及特殊键输入正常。
- [ ] 双向剪贴板按预期工作。
- [ ] 断开后能够无人值守重连且无需再次输入密码。
- [ ] 自适应显示可完整展示远端桌面。
- [ ] 连续使用期间无异常断线，并记录脱敏的 CPU/内存观察结果。
- [ ] Tailscale 暂停、对端离线和 RustDesk 未监听时能够清晰回退。

验收记录只写结果和匿名设备 A/B，不写真实地址、设备名、账号、密码或原始状态输出。
