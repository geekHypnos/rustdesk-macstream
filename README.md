# RustDesk MacStream

面向 Mac 间远程控制、配置与验证优先的 RustDesk 实验项目，非 RustDesk 或 Tailscale 官方项目。

**当前状态：方案阶段。尚未实现客户端增强，未验证性能收益，也未发布安装包。**

目标是在尽量保留上游架构的前提下，改善连接便利性，并通过实测定位和修复 macOS 性能瓶颈。Tailscale 为完全可选组件，不绑定作者账号。

## 首期范围

依据 v0.4：Tailscale 模块开发为首期必做，使用时仍完全可选、默认关闭。

1. 建立公开文档仓库，固定原版版本，在实际两台 Mac 上轻量验证连接和体验。
2. 完成安装、授权、被控端 Direct IP access 和认证配置、可选 Tailscale 手动连接及排障指南；由用户手动配置被控端。
3. 开发最小接入模块：本机安装及连接状态检测、官方入口、设备选择、在线状态和地址填入。区分需要登录、已登录但断开/暂停、已连接及未知；无法判断时不猜测，也不自动登录或重连。
4. 验证启用、跳过和关闭路径；连接、认证及错误提示复用 RustDesk 原有流程，不新增端口扫描或独立可达性诊断。模块关闭不停止官方 Tailscale 客户端。

首期不自动安装或登录 Tailscale，不读取认证凭据，不调用云端 API，不内嵌 VPN，不修改 ACL、出口节点或代理。设备在线不等于可远控，也不保证点对点直连；已登录不等于已连接。选择地址不保证对方运行 RustDesk 或已启用 Direct IP。失败时按指南检查设置、权限和网络策略，不直接归因为 Tailscale。

最小模块验收完成即停止扩展。性能补丁仅在实测问题且用户确认后启动；签名、公证及正式发布验收在决定对外分发时进行。当前尚未开发模块，文档不是功能完成证明。
